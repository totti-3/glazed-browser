# 🍯 Glazed

### A browser with a little more flavor.

**Glazed** is a modern, minimalistic Chromium-based browser built with vibes, ambition, and a love for clean design. Designed for **Linux and Windows**, Glazed aims to make everyday browsing feel smooth, lightweight, and effortless.

No unnecessary clutter. No overwhelming interfaces. Just the web, the way you want it.

---

## ✨ Features

- 🎨 **Modern UI** — A sleek, minimalistic interface with a focus on aesthetics.
- ⚡ **Chromium-Powered** — Built on Chromium for a familiar, modern web experience.
- 🐧 **Linux Support** — Built with Linux users in mind.
- 🪟 **Windows Support** — A desktop browsing experience for Windows.
- 🧼 **Clean & Minimal** — Less visual noise, more focus on what matters.
- 🛠️ **Vibe Coded** — Built through experimentation, creativity, and AI-assisted development.
- 🚀 **Built to Evolve** — An experimental project with room for new ideas and features.

## 🎨 The Vision

Glazed is built around a simple idea:

> **Your browser should feel as good as the websites you visit.**

The goal is to create a browser that feels intentional in every detail — from its interface to its overall experience.

Inspired by modern UI design, minimalism, and the freedom to experiment, Glazed is a project focused on making browsing feel fresh again.
